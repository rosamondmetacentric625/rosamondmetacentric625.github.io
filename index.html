🚀 What is TeleDrive?

TeleDrive is a free Android application that transforms a private Telegram channel into your own personal cloud storage. Think of it as having a secure, private drive that lives inside Telegram — a service you probably already use. You get automatic photo backup, optional end-to-end encryption for your most sensitive files, and a complete file manager to organize everything. No more juggling multiple cloud services. TeleDrive brings it all together in one familiar place.

✨ Key Features

  • 📸 Automatic Photo Backup: Set it and forget it. Every photo you take is automatically uploaded to your private Telegram channel, keeping your memories safe.
  • 🔒 Optional End-to-End Encryption: For files that need extra protection, enable end-to-end encryption. Only you can decrypt and view them.
  • 📂 Full File Manager: Browse, move, rename, delete, and organize files with an intuitive interface. Everything is at your fingertips.
  • 🎨 Modern Design: Built with Material You and Jetpack Compose, TeleDrive looks and feels native on your Android device.
  • ⚡ Fast & Reliable: Powered by TDLib (Telegram Database Library), ensuring quick uploads and downloads with minimal battery usage.

🔧 How to Set Up TeleDrive

After launching TeleDrive for the first time, you'll need to connect it to your Telegram account:

  1. Log in with Telegram: Enter your phone number and the verification code you receive via Telegram.
  2. Create or select a channel: You'll be prompted to choose an existing private channel or create a new one. This channel will serve as your cloud storage.
  3. Enable features: Decide whether you want automatic photo backup and whether to enable end-to-end encryption for sensitive files.
  4. Start using it: That's all! Your private cloud is now active. Upload files, organize them, and access them from any device with Telegram.

🛡️ Privacy & Security

Your privacy is paramount. TeleDrive uses your own private Telegram channel, which means only you (and anyone you explicitly add) can see the content. With optional end-to-end encryption, even Telegram itself cannot access your encrypted files. Your data stays yours — always.
